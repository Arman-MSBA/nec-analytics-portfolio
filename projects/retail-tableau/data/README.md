# Included Tableau extracts and source data

The preferred viewing files are the packaged workbooks in [`../workbooks/`](../workbooks/):

- [`retail-performance.twbx`](../workbooks/retail-performance.twbx), Module 7
- [`retail-analytics.twbx`](../workbooks/retail-analytics.twbx), Module 8

Each package includes Hyper extracts containing synthetic daily retail course data
and written notes. The extracts let Tableau display the saved dashboards without
the original source CSVs. No employer data are included.

The separate `.twb` definitions are data-free. They reference the project-relative
paths `Data/Sources/Module7_Dashboard_Retail.csv`,
`Data/Sources/Module8_Analytics_Retail.csv`, and `Data/Sources/Written_Notes.csv`.
To refresh from CSVs or use those definitions independently, provide the authorized
source files and reconnect in Tableau. The CSVs themselves are not included here.

Private source paths and connection credentials have been removed. The data are
academic exercises and should not be interpreted as verified retail operations.
Underlying course materials remain subject to their original terms.
