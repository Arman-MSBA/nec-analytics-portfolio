Project background on LinkedIn (opens in a new tab) The Boston Globe feature · 2023 (opens in a new tab)

The question

How can the repetitive work of drafting and publishing property listings take less time?

My contribution

I developed an AI-powered listing workflow that uses the ChatGPT API to create property descriptions and automate posting on Facebook Marketplace. I described the project publicly on LinkedIn, and it was featured in The Boston Globe in 2023.

Reported result

The project connected AI-generated listing copy to a practical posting workflow. In my public summary, I reported less manual preparation and more daily inquiries. These benefits are self-reported.

A specific task, connected to a workflow.

An independent ChatGPT API workflow for creating property descriptions and automating Facebook Marketplace posting.

  1. Use property information as the input.
  2. Create a listing description through the ChatGPT API.
  3. Connect the description to the posting workflow.

What I would measure next

The useful starting point for AI is a specific task: here, turning property information into a listing. A future iteration would measure preparation time, review quality, and publishing reliability against a documented baseline.

Evidence and scope

The public evidence describes the workflow and reported benefits. This case does not present a controlled experiment or verified conversion uplift, and it does not publish customer information, account access, or private source code.
