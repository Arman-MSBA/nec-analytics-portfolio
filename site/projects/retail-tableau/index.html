The question

How can a retail manager move from a headline KPI to the regional, category and time patterns behind it?

My contribution

I built the views, calculations and dashboard layouts, then paired them with written interpretation of the course retail data.

What it shows

Central leads sales at $44.57 million. Regional sales differ by about 1.4%, giving the category and time views useful context for a closer look.

How I approached it

  • Built an analytical overview, interactive insights and a KPI scorecard for sales, profit and order volume.
  • Connected regional and category views with filters, dashboard actions and a selected-region sales target.
  • Compared linear, exponential and polynomial trends, profit distributions and a four-cluster solution.
  • Placed automatic and custom seasonal forecasts side by side to examine their assumptions.

What I learned

A useful dashboard supports a sequence of questions: what changed, where the change occurred and which assumptions need testing before a decision.

Limits

The supplied retail data are synthetic course exercises. Trend fits and clusters are exploratory. No future-period forecast accuracy or realized sales improvement is claimed. These are static screenshots from the validated workbooks. The packaged workbooks include embedded extracts; refreshing from the original course CSV files requires those source files.

A useful next step

Test forecast choices on a later time period and compare forecast errors before using the projections to guide a decision.
