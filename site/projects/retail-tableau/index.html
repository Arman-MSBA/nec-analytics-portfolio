Where is retail performance changing, and what deserves a closer look?

Two Tableau coursework workbooks connect sales, profit and order KPIs with interactive exploration, trend comparisons and forecasting.

  • Tableau
  • Dashboard actions
  • Calculated fields
  • Forecasting
View project on GitHub (opens in a new tab)Reproduction notes (opens in a new tab)

The question

How can a retail manager move from a headline KPI to the regional, category and time patterns behind it?

My contribution

I built the workbook views, calculations and dashboard layouts, then paired the visual analysis with written interpretation of the course retail data.

How I approached it

  • Built an analytical overview, interactive insights and a KPI scorecard for sales, profit and order volume.
  • Connected regional and category views with filters, dashboard actions and a selected-region sales target.
  • Compared linear, exponential and polynomial trends, profit distributions and a four-cluster solution.
  • Placed automatic and custom seasonal forecasts side by side to examine their assumptions.

The result

The final submitted workbooks contain eight dashboard views and one four-point Tableau story: three dashboards plus the story in Module 7, and five dashboards in Module 8. Sanitized workbook definitions are available in the project repository.

Inside the workbooks

Original saved 192px workbook previews. Sanitized workbook definitions and sheet inventories are available in the repository.

What the work shows

A useful dashboard supports a sequence of questions: what changed, where the change occurred and which assumptions need testing before a decision.

Limits

The supplied retail data are course exercises. Trend fits and clusters are exploratory, and no future-period forecast accuracy or realized sales improvement is claimed.
